# Changelog

## 0.6.0 alpha

- Rebuilt the motion ruler as a responsive drag timeline with time ticks, hover feedback, saved-pose markers, and a stable pose preview.
- Reorganized the layered builder around Parts, Canvas, and a selected-part inspector with plain Artwork, Layout, Visibility, Attach, Movement, and Frames pages.
- Replaced the artificial three-way setup with separate Quick avatar and Layered avatar workflows.
- Added visible part hierarchy indentation and direct Add, Copy, Attach, Back, Front, and Delete actions.
- Added visible, configurable focused and Windows background keys for every expression.
- Added a direct **Keys…** button beside the expression list and clearer trigger behavior controls.

## 0.5.1 alpha

- Shortened the editor language and renamed the three setup paths to Quick character, Layered character, and Animated rig.
- Simplified workspace, section, frame-rate, and help labels.
- Rewrote the project page around downloading, making a character, and capturing it.
- Added a clear public roadmap and release limitations.

## 0.5.0 alpha

- Added per-part color tinting and custom capture backgrounds.
- Added 20, 30, 60, and 120 fps capture choices.
- Added a microphone restart control for device changes.
- Added release documentation, validation records, and the first public Windows package.

## 0.4.1 alpha

- Reworked the editor into separate rig, artwork, and performance workflows.
- Added visual artwork slots, an asset browser, creation wizard, contextual inspectors, menus, preferences, and tooltips.
- Improved save validation, backups, recovery, and build checks.
