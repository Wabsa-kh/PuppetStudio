# Contributing

Puppet Studio is an early Godot desktop project. Before opening a pull request:

1. Describe the user-facing problem and the final behavior.
2. Keep project files backward compatible unless a documented migration is included.
3. Do not copy competitor code, artwork, branding or proprietary file-format material.
4. Run `build.ps1` with `-FullChecks` on Windows. The build publishes only after source and exported-runtime checks pass.
5. Add focused validation for data-format, renderer, input or UI behavior that changed.

Please use GitHub issues for bugs and feature proposals. Include Help → System status when reporting runtime problems; remove anything you do not want to share.
